Overview

A crash report records what an app was doing when it stopped: each thread’s backtrace, the frame that failed and the binary images it had loaded. Read its Exception Type first, then the crashed thread.

  • Incident Identifier: a unique identifier for the report.

  • Hardware Model: the device the app ran on.

Symbolicate the backtrace

A backtrace names addresses until the build’s symbol files are uploaded:

Thread 0 Crashed:
0   Shop   0x0000000100a4c2f8 Cart.total() + 120
1   Shop   0x0000000100a4b9e0 CheckoutView.body.getter + 64
  1. Upload the build’s symbol files.
  2. Open the report again.
